# Mahalanobis distance — segment 평균 OR 마르코프 연속경고 (5장)

- 적용 입력: **원데이터 0.5초** (3장 성능표에서 OOF F1이 가장 높은 입력)
- 판정 간격: 2시점 = 0.2초마다 window 점수 계산
- 판정: segment 평균 ≥ T* **또는** window 점수 ≥ T_w 가 K번 연속
