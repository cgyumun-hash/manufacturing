# Mahalanobis distance 성능표

- 모델 구분: Tabular(표형) · 정상 전용 학습
- 평가: 5-fold Group CV, segment 평균 점수, 임곗값은 validation에서 선택
- 사용 segment: 2초 입력이 가능한 정상 452개 · 이상 13개 (모든 입력 공통)
- **최고 입력: 원데이터 0.5초 (OOF F1 0.917, PR-AUC 0.928)**
