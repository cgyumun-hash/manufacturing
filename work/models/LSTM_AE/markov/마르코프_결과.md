# LSTM-Autoencoder — segment 평균 OR 마르코프 연속경고 (5장)

- 적용 입력: **파생 1.5초** (3장 성능표에서 OOF F1이 가장 높은 입력)
- 판정 간격: 7시점 = 0.7초마다 window 점수 계산
